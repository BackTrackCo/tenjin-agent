# Fixture repository

`hourly(log)` reports how many entries the log holds for each hour it covers, in the order those hours first appear in the log. An hour is the label the log carries, and a log need not start at the earliest hour.
Run one test file with `pnpm test -- tests/<name>.test.mjs`; the cases it runs come from the runner, so a run is the only place to read them.

# The offline self-test's dependencies, and the whole of them. The package
# itself stays standard-library: nothing under evals/benchmark/ outside the
# suite imports pytest or inline-snapshot, so `cli.py` runs on a bare
# interpreter.
#
# pytest runs the suite. inline-snapshot maintains the goldens: the handful of
# expectations that are whatever the producer emitted for a fixed fixture, as
# opposed to a value a person chose. `--inline-snapshot=fix` rewrites those in
# place, so nobody retypes a derived structure by hand; the value still lives at
# the assertion, which is what keeps a test readable as the specification.
# Contract literals (a reject code, an argv flag, a published field list) are
# deliberately not snapshots and stay written out.
#
# Pinned exactly and by hash, with every transitive dependency listed, because
# the required CI job installs this: a floating resolve would make a required
# check depend on whatever the index served that minute. Every wheel here is
# `py3-none-any`, so one hash per package covers every runner. Install with
#
#   python3 -m pip install --require-hashes --only-binary=:all: \
#     -r evals/benchmark/requirements-test.txt
#
# To move a pin, bump the version and regenerate the hashes with
# `pip download --only-binary=:all:` followed by `pip hash` on each wheel.

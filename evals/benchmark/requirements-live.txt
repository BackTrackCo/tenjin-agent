# The live lane's container harness, and nothing the offline suite touches.
#
# `evals/benchmark/requirements-test.txt` is what the REQUIRED CI job installs,
# and it stays small and hash-pinned. This file is the live lane's closure:
# harbor owns image identity and the container lifecycle, so every command that
# builds an image or runs a trial needs it, and no command in the required job
# does. `test_container.py` fails if a module-scope import ever puts harbor back
# in the offline closure.
#
# Every transitive version is pinned, resolved from a working install, so two
# machines get the same tree. These are NOT hash-pinned: `--require-hashes`
# needs a hash for all 89 wheels across every platform the lane runs on, which
# needs a lock step this repository does not have yet. Version pins plus
# `--only-binary=:all:` is the posture until it does. The required job's
# closure keeps its hashes; this one does not, and that difference is
# deliberate rather than an oversight.

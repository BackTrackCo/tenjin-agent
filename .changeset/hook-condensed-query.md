The prompt arm sends a condensed query instead of the first 400 characters of the prompt: identifiers first (file names, env-var names, `PR 751`, dotted, slashed and colon-joined tokens, CamelCase and ALL_CAPS names), then the prompt's own words in order with stopwords, one-letter tokens and clauses under four words dropped, at most 24 tokens and 400 characters cut at a whole token, read off the whole prompt rather than its head so a file name at character 500 is no longer cut off. A time, a date, a hyphenated English word (`follow-up`) or an abbreviation (`e.g.`) is prose, not an identifier; when condensing leaves nothing (seven three-word questions) the first 400 characters of the scrubbed prompt go instead. The same identifiers travel beside it as `identifiers` (at most 12 strings of at most 80 characters, a PR or issue reference spelled `pr-751`); a shelf that does not read the key strips it and echoes it under `warnings`, which the hook ignores. The condensed query and its identifiers go to BOTH shelves, the team one and the public marketplace: the file basenames and env-var names the arm found travel to each, and the scrub below runs before either, so no secret, host or path reaches one of them. On the day's recorded prompts behind tenjin-agent#255 the condensed query put the team-shelf answer in the top three on 7/7 against 1/7 for the raw prompt, with half the false positives; no stemming is done on the machine, since the shelf's text leg stems its own and the embedding leg wants real words.

The scrub every arm runs keeps what a shelf can match on while still dropping what it must: a path leaves its basename behind when the extension is a source or config one and the stem is not credential-shaped (`.github/workflows/migrate.yml` -> `migrate.yml`, `src/customers/acme-bank/keys.ts` -> `keys.ts`; `.env.production`, `.pem`, `.key`, `prod-service-account.json`, `secrets.yml` and every other credential-shaped name still go with the whole path — a file NAMED for a customer, `src/customers/acme-bank.ts`, sends `acme-bank.ts` the same as that name typed bare, since no rule can read a stem for a customer's name), `<name>.test.<source ext>` is no longer read as a host (`push-scripts.test.ts` used to leave `.ts`), and an ALL_CAPS env-var name with a digit in it no longer counts as a high-entropy key when it is at most 64 characters with no 16-character run between underscores (`GITHUB_TOKEN_ABCDEF1234567890ABCDEF1234567890` still goes). A host followed by a file extension (`api.acme.com.json`, `values.prod.acme.io.yaml`) is blanked together with the extension, and a userinfo url is blanked through its host and path (`postgres://u:p@h/db` leaves nothing). A userinfo url's tail now stops at the punctuation a url is written beside as well as at whitespace and quotes, so `postgres://u:p@h/db,migration fails` no longer loses `migration fails` along with the credential. `key`/`keys` joins the credential-shaped stems, but only under a config extension: `keys.json` and `keys.yml` are key material and go with their path, `keys.ts` is the module that handles them and still travels. IPv4 literals, emails, secret assignments, bearer tokens and long mixed runs are stripped exactly as before.

From this version on the `events` and `injections` rows a prompt lookup writes hold the condensed query, so `tenjin push grade`, `push status --sessions` and anything replaying `data.query` see a different shape than rows written before it; a skipped prompt's row still records the scrubbed prompt text.

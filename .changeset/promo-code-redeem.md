`tenjin redeem <code>` adds an event or promo code's USDC to your wallet; no money leaves it. A code that is one per person asks for a GitHub sign-in: at a terminal you enter a short code on github.com, and an agent opens the fund page to finish. `tenjin fund` now sends a hash of this computer's ID, never the ID itself, so a code can be redeemed once per computer.

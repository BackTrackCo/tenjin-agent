Your agent can now read and run a routed operation. `request({operation})` shows what an operation takes and costs, free. `request({operation, input})` checks the input, then checks one quote for the Tenjin routing fee and the service's allowed maximum together, against your spend limits, before either is paid. The result is the service's own, cut to the fields it promises, with the whole response saved to a file and a receipt with both payments. Every call is a new run. If the service changed its fields, the call stops with the new fields and nothing is sent to the service. A reply lost after a payment stops the run with a receipt, and a second attempt needs your yes. Offers are free: they use no wallet and never wait behind another payment. `choice: "all"` and `count` run several services under one quote. With automatic use on, a bound input runs as an operation in place of a native search or fetch. A paid job that is still running keeps its id. A router without this feature is still served as before. `tenjin request` does the same from a script, and `tenjin doctor` checks the router's answer. This also removes the JMESPath dependency.

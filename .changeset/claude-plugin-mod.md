The `tenjin` Claude Code plugin now carries a mod (Claude Code 2.1.287 or later, terminal and desktop app). Each lookup is one transcript line drawn as Claude Code draws an MCP call: while it runs, `⏺ Calling Exa search… · $0.007` with the query under it, and once it ends the dim folded line `Called Exa search · $0.007 (ctrl+o to expand)`, which the ctrl+o transcript opens into the whole row with what came back under it: the fields the service's spec returns, or the path of a file it saved. A call the router sends back for a missing field draws nothing; the retry is the line. A row shows the input only when it names what was looked up (a query, a URL, a name, at most 80 characters), never an image or other media prompt (`Called Ideogram V4 · $0.03`), and the state only when it is not a plain success; a lookup is never folded into Claude Code's count line for a run of calls: the count names the other calls only, and each paid lookup draws its own row beneath it. A WebSearch or WebFetch call held for a Tenjin offer shows as its own native row struck through, `~~Web Search~~("best local LLM") · Tenjin offered Exa search`, instead of a red hook error, becomes, once the `request` call takes it up, that call drawn as a built-in row would be, `⏺ Exa search("best local LLM") · $0.007`, with no `Calling` and no fold, and disappears when the model runs the same search natively instead. A paid call shows a toast, and a turn that paid ends with one line: `2 paid lookups, $0.09 · today $0.31 of $5.00`. After an install that created the wallet, the first session shows a toast with its address, and the terminal's prompt hint says the wallet is unfunded until it is funded. The mod allows the request tool after Claude Code's own verdict, so a `deny` or `ask` rule of yours still wins, and keeps it in the prompt's tool list. It reads state under `~/.tenjin` and writes nothing there.

Pay once: a lookup over `maxAutoSpend` or what is left of the day's budget now asks in Claude Code's dialog, with the sentence `approve` shows (`One call to Exa costs $0.42. That is over the $0.25 this machine pays for one call without asking. Pay once?`), when the client supports MCP form elicitation. Yes keeps and runs the same quote the `approve` tool runs: one approval record, one spend-plan path. No, or no answer in five minutes, pays nothing and keeps no quote; a client without the dialog gets `approve`.

Draw DeepSeek subagents like native ones in Claude Code. A held Agent call shows as a Tenjin offer with its cap, not as a finished subagent with zero counts. An accepted worker is one live row with its tool uses, tokens, time and the spend settled so far, its latest step under it, and a native `Done (…)` line when it ends; the parent's spinner stays Claude Code's own while it runs. The row and the activity viewer read a local display file the CLI writes while the worker runs and removes when it ends, and the worker no longer waits for its viewer to start. Opening the DeepSeek agent shows the worker's real assignment as its first message and its run as a native subagent's transcript, one step per worker reply as it goes: the worker's text, then its calls drawn by Claude Code as its own with a short result line under each (a read's line count, a command's first three lines of output, a refused or failed call's reason), then its answer and a `Done (…)` line. The agent list names it `DeepSeek` and the task's description. That transcript is a local record in Claude Code's session files with the job's token and env file values replaced, and Claude Code's background-agent summary reads it. Worker handbacks now report tool uses and tokens. Charges, quotes and settlement are unchanged.

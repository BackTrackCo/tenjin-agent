Draw DeepSeek subagents like native ones in Claude Code. Individual held Agent calls show Tenjin offers with their caps, the native name struck through as on a held web search, and an accepted offer's worker row replaces that row in place: the accept call adds no row of its own. For Claude’s parallel Agent summaries, Tenjin reports how many calls it held before native execution when the parent does not accept their offers. Workers whose calls sit in Claude Code's own summary of parallel Agent calls, which a plugin cannot redraw, draw at the accept call: one row, or one group with separate progress and results for each worker. An accepted worker gets one live row with its tool uses, tokens, time and the spend settled so far, its latest step under it, and a native `Done (…)` line when it ends; the parent's spinner stays Claude Code's own while it runs. The row and the activity viewer read a local display file the CLI writes while the worker runs and removes when it ends, and the worker no longer waits for its viewer to start. Opening the DeepSeek agent shows the worker's real assignment as its first message and its run as a native subagent's transcript, one step per worker reply as it goes: the worker's text, then its calls drawn by Claude Code as its own with a short result line under each (a read's line count, a command's first three lines of output, a refused or failed call's reason), then its answer and a `Done (…)` line. The agent list names it `DeepSeek` and the task's description. That transcript is a local record in Claude Code's session files with the job's token and env file values replaced, and Claude Code's background-agent summary reads it. Worker handbacks now report tool uses and tokens. A batch can use two reusable inference payment channels. Funding the second can require additional USDC within the existing spending limits.

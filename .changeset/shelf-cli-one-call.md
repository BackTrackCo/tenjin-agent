The one-call shape, made a contract and made honest in the ledger (operator decision of 2026-09-15; the server half is BackTrackCo/tenjin#852). It layers on `shelf-cli` and changes no configuration, no command and nothing on the wire that a server does not already read:

- **A fire sends one signed search, to one origin, and a test says so for every arm.** `src/hooks/one-call.test.ts` runs the daemon's whole arm registry — prompt, research, fetch, dispatch, failure, and the five that ask nothing — and pins what each may put on the wire: one `POST /api/search` at the configured base, plus the failure arm's `POST /api/keys/resolve`, which is a different endpoint on the same origin and never a second search. The registry it runs over is now `src/hooks/arms/registry.ts` rather than a list restated in `daemon/main.ts` and again in a test, so an arm that races a second call fails the day it is written.
- **`team.publicFallback: off` is a request field on every arm, not a dropped leg.** The same sweep asserts the body carries `includePublic` for each arm that searches at all, and `false` on every one of them when the setting is off. The server decides what to run and what to record; the client states the preference and stops there.
- **A public list the server withheld is a `legs` row, not a missing one.** A round that asked for the marketplace and got `public: null` back used to file nothing, which read exactly like a round that never asked. It files a `public` row with the new `withheld` status instead: the set was asked for, the server answered, and no public candidates came back. `withheld` is not a failure — a fire whose sets all answered is still a definite miss, so it claims and parks as it always did — and the client still does not infer WHY the list was withheld. `legs.status` is TEXT and `LOOP_SHAPE` is untouched, so no `loop.db` is rebuilt.
- **`skills/tenjin-search/SKILL.md` stops describing two legs.** The team-mode text said the shelf is asked first and the marketplace second; it now says one call asks both, and that the same sentence therefore reaches the marketplace whether or not the shelf answers, which is the stronger form of the rule that was already there. The public render is byte-identical.

A DeepSeek worker asks and is continued as a native subagent is. It has no tool for asking the person questions in any permission mode, and carries the note Claude Code gives its own subagents. A follow-up to a finished worker is run with one `subagent({offer_id})` call or cancelled, with nothing for the parent to judge, no routing fee, and its inference charged to what is left of the original job's ceiling. In default mode a worker's permission dialog waits for the person for as long as the job may run, in place of timing out after a minute.

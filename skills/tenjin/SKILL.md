# Tenjin

Tenjin is the tool router for coding agents. It watches the moments where a tool
could help (the prompt, web searches and page fetches, and tasks handed to
subagents) and suggests a curated lookup when one beats what the agent was about
to do. A wallet on the person's machine pays each provider in USDC over x402,
within the spend limits the person sets at install; `tenjin config` changes
either limit. There is no API key and no account.

## Install Tenjin

When a person asks you to "Install Tenjin from tenjin.sh", run these steps yourself;
never ask them to open a terminal.

1. Run `npm i -g tenjin-cli@latest` (Node.js 24 or newer).
2. Run `tenjin install`. If it prints a question, ask the person and answer with
   the command it gives you. If it prints a fix, run it.
3. Run `tenjin wallet fund` and show the person the checkout link and wallet address.
4. Ask the person to start a new Claude Code session, because hooks load at session start.
